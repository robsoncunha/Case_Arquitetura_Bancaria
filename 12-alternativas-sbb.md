# SBB — alternativas de implementação

As opções abaixo são candidatas, sem fornecedor selecionado.

| ABB | SBB candidato | Critérios de escolha |
|---|---|---|
| Cliente | Serviço existente exposto por API | Cobertura, disponibilidade e segurança |
| Cashback | Serviço próprio ou solução de terceiros | Regras, custo total, auditoria e portabilidade |
| Integração | API gateway, adaptador e mensageria | Contratos, suporte, recuperação e operação |
| Conciliação | Componente existente ou novo | Cobertura de exceções, rastreabilidade e custo |

SBB é uma solução concreta que realiza uma ou mais capacidades arquiteturais. Confirmar produtos, licenças e operação antes de decidir.
