# Fase C — dados

Identificar fontes e responsáveis pelos dados de cliente, adesão, transação, parceiro, regra e benefício. Validar identificadores, qualidade, retenção, acesso e necessidade de dados pessoais. Definir linhagem, trilha de auditoria e reconciliação. A consistência e o prazo de atualização devem ser acordados por operação; não há metas numéricas fornecidas.
